## Overview

Project Rune is a top-down action project built around large enemy encounters, powerful abilities, character builds, and escalating combat. My work covered gameplay implementation and the supporting progression and interface systems visible throughout the demonstration.

## Edited gameplay showcase

The original gameplay test was condensed into a focused action reel. The edit removes setup screens, long traversal sections, and pauses while preserving four combat sequences that demonstrate enemy density, ability effects, kill-combo progression, and the visual intensity of the game.
